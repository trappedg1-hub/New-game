# Project instructions

## HERO-01 costumes and animation

Read [`ArtStudio/Docs/06_hero01_quality_reference_v3.md`](ArtStudio/Docs/06_hero01_quality_reference_v3.md) before creating or changing HERO-01 art, costumes or animation. The user approved the jointed V3 at runtime commit `22f50059fbfd63562c3034b689438819679df5f4` as the continuing quality reference, not as a pose or movement template.

- Preserve the approved character identity and at least the reference's visual and animation quality. Do not copy its pose. Give each new costume a genuinely new, concept-appropriate pose and individually designed motion; do not reuse previous variants' motion mechanics or choreography as a template. Adapt clothing movement to the new garment.
- Keep the approved V3 reference, V1, V2 and `ArtStudio/Generated/Approved/` intact unless the user specifically permits changes. Develop new work separately. Approval of the reference does not automatically approve a new costume or unused studies.
- Report real testing and known limitations honestly; an emulated browser is not a physical iPhone Safari test.

## Turbo mode: efficiency without quality loss

- Use already established context; investigate or reread files only when needed. Parallelize independent technical work, avoid unnecessary intermediate results and repeat completed checks only when affected changes or new problems require them.
- Fix problems locally instead of restarting the workflow. Use effective tools and keep reports concise.
- Accelerate preparation, processing and technical checks, never by reducing the quality, detail, resolution, specification coverage or generation time needed for art or animation. Do not substitute rough sketches for finished artwork.
- Request the highest available native image quality and resolution. Check actual output dimensions and disclose any shortfall; upscaling does not recover the original lost detail.
