# HERO-01 — Character Sheet (Главная героиня)

Статус: v2 (2026-11-04). Изменения — только по решению пользователя, фиксируются в change log.

**Стиль:** все изображения генерируются в утверждённом стиле —
`ArtStudio/Style/art-style-guide.md` (Style Anchor v2 + чек-лист качества).
Референсы стиля — только стиль, НЕ внешность: blonde/синие глаза с них НЕ переносятся.

## Канон внешности (НЕ меняется между изображениями)

| Признак | Канон |
|---|---|
| Возраст | Явно взрослая, поздние 20-е (25+) |
| Волосы | Очень длинные (до поясницы), тёмно-шоколадный (не чисто чёрный), слегка волнистые, глянцевый блеск, мягкий боковой пробор |
| Глаза | Большие выразительные anime-глаза, рубиновые/гранатово-красные, многослойные блики |
| Кожа | Тёплая, **слегка загорелая** (sun-kissed tan, тёплый оливковый подтон) — не фарфорово-бледная |
| Лицо | Зрелое, элегантное, выразительное; мягко очерченная линия челюсти, тонкие изогнутые брови, аккуратный нос, полные губы |
| Фигура | Пышный hourglass; узкая выраженная талия, широкие бёдра; длинные стройные ноги |
| Дополнительно | Без тату, без пирсинга, без канон-аксессуаров (ювелирка — только по сцене) |

Предлагающий signature-деталь (ожидает решения): маленькая родинка под правым глазом.

## Style anchor

**База = Style Anchor v2 из `ArtStudio/Style/art-style-guide.md`** (утверждённый стиль
референсов 2026-11-04). Вставлять дословно в каждый промпт + строку
`warm lightly tanned sun-kissed skin` из character anchor.

Направления-вариации для будущих экспериментов (по запросу):
visual novel art, RPG key visual, semi-realistic, digital painting — **на текущий момент
заморожены**: базовый стиль утверждён референсами.

## Правила консистентности

- **Никогда не меняется:** цвет/длина/волнистость волос, цвет глаз, тон кожи (тёплый, с загаром),
  пропорции фигуры, форма лица.
- **Может меняться (по тесту):** одежда, поза, эмоция, место действия, ракурс.
- **Итерации:** не более 2–3 изменений промпта за раз.
- **Качество:** сверка каждого результата с чек-листом из art-style-guide.md §13.
