# Art Style Guide — «New Game»

Статус: **утверждён пользователем** (референсы присланы 2026-11-04).
Это постоянный визуальный стандарт для всех материалов игры: персонажи, одежда, эмоции, позы,
CG-иллюстрации, дополнительные изображения. **Каждую новую генерацию сверять с этим гайдом.**

## 1. Стилистическое семейство

«Premium anime game character art» — уровень high-end anime game CG (премиальный gacha-тир).
Гибрид: **anime-голова** (большие глаза, маленький нос, мягкая челюсть) + **полустилизованное
зрелое тело** (hourglass, выраженная грудь/бёдра, длинные ноги).
Положение между «flat anime» и semi-realism: чистый, глянцевый, «продуктовый» вид —
как официальные ассеты premium-игры. Никаких живописных мазков.

## 2. Линия (lineart)

- Чистая, ровная, тёплый почти-чёрный / тёмно-коричневый цвет линии.
- Тоньше на лице, чуть толще на одежде и по контуру волос.
- Без скетчевости, без «поблёкших» участков, без скелетных линий.

## 3. Заноска (shading) и материалы

- Формула: base flat → 2–3 шага cel → мягкий airbrush-градиент.
- Деликатная ambient occlusion в складках (под грудью, у пупка, локти, сгибы).
- **Кожа:** гладкая, почти без текстуры, лёгкий глянец; маленькие specular-точки
  (нос, подбородок, скулы); мягкий румянец.
- **Волосы:** глянцевые, пучками прядей, 1–2 яркие полосы-блика, тёмные корни,
  отдельные выбившиеся пряди.
- ЗАПРЕЩЕНО: масляные мазки, холстовая текстура, «полупоточная» живописная кожа.

## 4. Лицо и глаза

- Большие anime-глаза: радужка с радиальным градиентом, limbal ring, 2+ блика,
  плотная верхняя линия ресниц, проработанная нижняя ресница.
- Маленький нос (одна линия / намёк на ноздри), маленькие глянцевые губы,
  мягкая линия челюсти, мягкий румянец.
- Выражение: выразительное, но собранное — уверенность, кокетство, лёгкая улыбка.

## 5. Пропорции и анатомия

- Стилевой hourglass: заметно узкая талия, выраженная грудь и бёдра, длинные ноги.
- Худые руки, длинные изящные пальцы (проверять количество пальцев!).
- Ступни: стилизованные, но анатомически правильные (свод, форма пальцев под обувью).
- Поза-основа: contrapposto, перенос веса на одну ногу, лёгкий 3/4 поворот.

## 6. Свет

- Мягкий студийный key с передне-верхнего направления, деликатный rim/edge light
  (особенно по контуру волос), низкий–средний контраст.
- Без жёстких чёрных теней; драматичный свет (бал, свечи) — только по задумке сцены.
- Фон: чёрный/прозрачный для ассетов; для CG — простой атмосферный фон с мягким боке.

## 7. Цветовая палитра

- Одежда: контрастный чёрный как база + насыщенные акценты (красный, белый, золото, фиолет).
- Кожа: тёплый ivory; для HERO-01 — с лёгким загаром (warm sun-kissed tan).
- Фон/среда: приглушённые тона, не конкурируют с персонажем.

## 8. Одежда и эстетика fanservice

- **Ткань ведёт себя реалистично:** чёткие плиссе юбки, паттерн кружева на бортах и
  топах чулок, гarter-ремни, разрез, кроп-топы с талией.
- **Полупрозрачность:** просвечивание + глянцевые полосы + видный паттерн (кружевные топы).
- **Материалы точно:** patent-кожа/лакировка — резкие отражения; сатин — мягкий глянец;
  матовые ткани (хлопок, сатин-мат) — мягкий градиент.
- **Всё изящно и неэксплицитно:** кружево, разрезы, backless, открытый живот, чулки,
  каблуки — в норме; нагота — нет.
- Повторяемые «фирменные» типы обуви: платформенные Mary Jane с пряжкой,
  заострённые каблуки, ботильоны, кроссовки (sporty-варианты).

## 9. Ноги и ступни

- Гладкий градиентный занос ноги; проработанные колени и лодыжки (деликатная AO).
- Чулки: полупрозрачные, мягкий глянец, кружевной scallop-топ с чётким паттерном.
- Обувь прорабатывается по материалу; форма стопы под ботинком анатомически верна.
- Художественные крупные планы ног/обуви (detail study) — разрешены, неэксплицитно.

## 10. Позы и ракурсы

- Стойка contrapposto; сидя (кресло, диван, край кровати); на коленях; вид со спины; 3/4.
- Одна фokal-жест: рука к губам, рука в волосах, бокал, перекинутая прядь.
- Ракурсы: полный рост (ассет), по пояс, портрет, крупный план элемента;
  камера на уровне или слегка снизу.

## 11. Композиция

- Ассеты персонажа: чистый cutout на прозрачном/чёрном фоне, единый масштаб,
  читаемый силуэт.
- CG-сцены: простой атмосферный фон + мягкое боке, персонаж — единственный фокус.
- Character sheets: сетка одинаковых масштабов, прозрачный фон (см. ref_02).

## 12. English Style Anchor v3 (вставлять в КАЖДЫЙ промпт дословно)

> in EXACTLY the art style of the attached reference images — same lineart character, same
> shading method, same rendering quality, same lighting, same clean high-clarity color palette.
> Reproduce the style faithfully, do not invent a new style, do not copy the reference
> characters' faces or identities. Thin uniform warm dark lineart, bright airy cel shading with
> soft warm gradients and subtle ambient occlusion, smooth glossy skin with minimal texture,
> large bright open anime eyes with glassy radial-gradient irises and a large upper highlight,
> simple small nose, small plump glossy lips, soft round cheeks with subtle blush, glossy wavy
> hair with strong bright highlight bands and distinct strand clumps, dark neutral backdrop,
> soft studio key light with gentle rim light, low-contrast elegant lighting, crisp polished
> official game artwork

Для HERO-01 поверх якоря: `warm lightly tanned sun-kissed skin` + character anchor из
character sheet. (Anchor v2 заarchивирован — был слишком generic, см. §15.)

## 13. Чек-лист качества (сверка каждой генерации)

- [ ] Чистая, равномерная линия (без скетча)
- [ ] Лицо по канону: форма/цвет глаз, брови, нос, губы, румянец
- [ ] Волосы: цвет, длина до поясницы, волнистость, глянцевые блики
- [ ] Кожа: тёплая, слегка загорелая (HERO-01) — не фарфорово-бледная
- [ ] Заноска: cel + мягкие градиенты, БЕЗ живописных мазков
- [ ] Ткани: плиссе / кружево / полупрозрачность проработаны
- [ ] Чулки и обувь: верный материал и паттерн
- [ ] Свет: мягкий key + rim, без жёстких теней
- [ ] Пропорции: hourglass, длинные ноги, изящные руки
- [ ] Композиция: чистый фон, читаемый силуэт
- [ ] Неэксплицитно

## 14. DO / DON'T

| DON'T (анти-паттерны) | DO (цель) |
|---|---|
| Живописные мазки, масляная текстура | Чистый lineart + градиентный cel |
| Фарфорово-бледная кожа (у загорелого персонажа) | Тёплая глянцевая кожа с лёгким загаром |
| Скромная/рваная линия | Ровная линия с осознанным весом |
| Упрощённый «мультяшный» облик | Зрелые выразительные черты |
| Наяга, эксплицитные углы | Изящный неэксплицитный fanservice |
| Дрейф внешности между картинками | Жёсткая идентичность по character sheet |

## 15. Style Replication Protocol (добавлено 2026-11-04 после фидбэка на Test 01 v2)

**Принцип:** текстового описания стиля недостаточно — модель по умолчанию тянет к собственному
generic anime-стилю. Поэтому **каждая генерация ОБЯЗАТЕЛЬНО получает референсы как
визуальный ориентир** (параметр `images`):

1. Стилевой референс для ВСЕХ генераций: `references/style_ref_01_fullbody.png`
   (самая чёткая прорисовка лица/глаз/кожи).
2. Для тестов с акцентом на одежду/чулки/обувь (test03, test04, test05) добавлять
   `references/style_ref_02_charasheet.png` (ткани, паттерны, обувь).
3. **Identity-референс HERO-01 (обязателен для всех генераций героини):**
   `../Generated/Approved/HERO-01_canon_portrait.png` — канон внешности (APPROVED v3.1).
   Роль: лицо/волосы/глаза/тон кожи/tan lines/фигура — ТОЛЬКО идентичность; стиль — не брать.
4. В промпте — дословно: `in EXACTLY the art style of the attached reference images ...`
   (Style Anchor v3, §12) + жёсткое: `do not copy the reference characters' faces, hair colors
   or identities` + идентификация утверждённой HERO-01 v3.1: golden-blonde glossy waves,
   violet-purple eyes, lightly tanned skin с заметными tan lines. Тёмноволосый вариант с
   рубиновыми глазами — архив, в новых генерациях запрещён.
5. Промпт содержит МИКРО-ПРИЗНАКИ стиля (не абстрактные теги): «bright open eyes with large
   glassy highlight», «thin uniform warm dark lineart», «bright airy cel shading»,
   «strong bright hair highlight bands», «clean high-clarity palette, black clothing».

**Журнал дрейфа (что уносилось при текстовом промпте без референсов):**

| Версия | Дрейф |
|---|---|
| v1 (generic prompt) | semi-realistic живописная кожа, бледный фарфор, мягкая линия |
| v2 (anchor v2, без референсов) | smoky тяжёлые глаза с liner'ом, реалистичные пропорции лица, тяжёлая серая линия, muddy тёмная палитра (тёмно-фиолет + золото), ювелирика вне канона |
| test02 v1 (full-body, 2026-11-04) | **identity drift**: лицо/причёса/глаза style-референса (blue eyes, крестовая клипса, челка, young face, поза скопирована). Причина: style-референс — full-body той же блондинки и перетянул identity в full-body фрейминге |

**Рецепт против identity drift (проверен на test02 v2):**
1. **Identity-референсы ПЕРВЫМИ** в images-списке (canon + лучший утверждённый тест),
   style-референс — последним.
2. **Два identity-референса** для full-body фреймингов (canon-портрет + утверждённый портрет).
3. **Явные запреты** в промпте: `NO straight bangs, NO hair clips, NO hairpins, NO hair
   accessories; eyes violet-purple, NOT blue; mature late-20s face, NOT teenage`.
4. **Поза, отличная от позы style-референса** (чтобы не копировать жест).
5. Формулировка: «The first N attached images show the SAME target character — identity from
   them ONLY; the last attached image is the art-style reference ONLY».

**Если кандидат снова дрейфует:** усилить микро-признаки промпта / сделать одиночную
генерацию (без offer_options) в отдельный файл для контроля.
