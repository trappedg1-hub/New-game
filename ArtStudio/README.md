# ArtStudio — художественная библиотека «New Game»

Premium anime fanservice clicker (браузерная игра). Цель: выбрать генератор и художественный
стиль, способные стабильно создавать изображения одной и той же героини (HERO-01)
с разными эмоциями, одеждами, позами и ракурсами.

## Текущий статус

- Канон HERO-01 v3.1 утверждён; композиционные тесты Stage 1 — **5/5**, позы Stage 2 — **5/5**.
- Сет эмоций Stage 3 — **6/6 APPROVED**; отдельные портреты находятся в `Generated/Approved/`.
- [Stage 4 — наряды](Docs/04_stage4_outfits_plan.md): пляжный образ и горничная утверждены; вечерний образ — v1 PARTIAL, v2 ждёт оценки.

## Структура

| Путь | Назначение |
|---|---|
| `Character/` | Character sheet: канон внешности, prompt-якоря, правила консистентности |
| `Docs/` | Планы раундов, исследование возможностей генераторов и стилей |
| `Prompts/` | Финальные промпты: один файл на каждый тест (статус, модель, changelog) |
| `Reviews/review-log.md` | Оценки пользователя (APPROVE / PARTIAL / REJECT), замечания, выводы |
| `Generated/Experiments/` | Эксперименты — все неутверждённые изображения |
| `Generated/Approved/` | Утверждённые референсы. **Перезапись без явного разрешения запрещена** |
| `Tools/` | Воспроизводимые локальные операции обработки экспериментальной графики |

## Workflow

1. Промпт фиксируется в `Prompts/testXX_*.md` (character anchor + style anchor из `Character/`).
2. Генерация в режиме сравнения: 2 кандидата от разных моделей → пользователь выбирает сильного.
3. Показать результат пользователю → оценка: **APPROVE / PARTIAL APPROVE / REJECT** + комментарии.
4. Записать в `Reviews/review-log.md`: что удалось, ошибки, что улучшить в промпте.
5. Сохранить: утверждённое → `Generated/Approved/`, остальное остаётся в `Generated/Experiments/`.
6. Коммит в GitHub — только после проверки, что файлы реально записаны.

## Правила

- Внешность берётся ТОЛЬКО из `Character/HERO-01_character-sheet.md`, якорь вставляется дословно.
- В итерации меняется не более 2–3 параметров промпта (не всё сразу).
- Все изображения художественные и неэксплицитные.
- Утверждённые референсы не перезаписываются без явного разрешения.
