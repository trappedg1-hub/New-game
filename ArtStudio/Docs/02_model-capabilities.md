# Возможности генераторов (заполняется по ходу)

## Доступные инструменты

- **generate_image** — генерация text→image и правка по референсам; режим сравнения:
  2 отдельных кандидата от разных моделей, пользователь выбирает один (выбранный сохраняется
  в целевой файл, остальные — в `Unselected files`). Имя модели задавать нельзя — только результат.
- **image_search** — поиск референсных изображений из веба (для уточнения промптов, раунд 2+).
