# Раунд 1 — пять композиционных тестов

**Цель:** проверить героиню в ключевых композициях и найти более сильную модель генератора.

**Метод модели:** имя конкретной модели выбрать нельзя — только система его назначает.
Поэтому каждый тест генерируется в режиме сравнения: **2 кандидата от разных моделей**,
пользователь выбирает более сильного. По итогам 5 тестов видно, какая модель стабильно выигрывает.

**Стиль:** единый базовый (premium anime game CG + high-detail digital painting) во всех 5 тестах,
чтобы сравнение было честным. Остальные 4 направления стилей — раунд 2, на утверждённой героине.

## Тесты

| # | Файл | Композиция | Акцент |
|---|---|---|---|
| 1 | `test01_portrait` | Портрет по грудь, 3/4 поворота | Максимальная детализация лица |
| 2 | `test02_fullbody` | Полный рост, стойка, 3/4 | Пропорции фигуры, силуэт |
| 3 | `test03_stockings_heels` | Сидя в кресле, бальный зал | Чулки + высокие каблуки, элегантность |
| 4 | `test04_feet_study` | Крупный план ног, диван | Ноги и ступни, анатомия, педикюр |
| 5 | `test05_loungewear` | На краю кровати, утро | Кружево + полупрозрачный шифон |

## Протокол

Каждый тест: 2 кандидата → выбор пользователя → оценка **APPROVE / PARTIAL / REJECT** + комментарии
→ запись в `Reviews/review-log.md` (что удалось / ошибки / улучшение промпта) → следующий тест.

Все изображения художественные и неэксплицитные.
