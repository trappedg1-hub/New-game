# Раунд 1 — пять композиционных тестов

**Цель:** проверить героиню в ключевых композициях и найти более сильную модель генератора.

**Метод модели:** имя конкретной модели выбрать нельзя — только система его назначает.
Поэтому каждый тест генерируется в режиме сравнения: **2 кандидата от разных моделей**,
пользователь выбирает более сильного. По итогам видно, какая модель стабильно выигрывает.

**Стиль (обновлено 2026-11-04):** пользователь утвердил референсы художественного стиля →
создан `ArtStudio/Style/art-style-guide.md` (Style Anchor v2). Все тесты генерируются в этом
стиле; каждый результат сверяется с чек-листом гайда §13.
**Раунд 2 (сравнение 5 направлений стилей) — отменён:** базовый стиль зафиксирован референсами.

## Протокол

Каждый тест: 2 кандидата → выбор пользователя → оценка **APPROVE / PARTIAL / REJECT** + комментарии
→ запись в `Reviews/review-log.md` (что удалось / ошибки / улучшение промпта) → сверка с чек-листом
гайда → следующий тест.

Все изображения художественные и неэксплицитные.
