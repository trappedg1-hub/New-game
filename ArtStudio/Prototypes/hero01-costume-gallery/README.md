# HERO-01 — каталог образов

Отдельный обзор для пользователя: три анимированных образа (Night Step, Yoga и горничная с версиями V1/V2/V3), пять утверждённых статичных костюмов без анимации и отдельная вкладка для уточнения. Пользователь одобрил анимацию Night Step; V2 горничной — эксперимент, а не одобренная база. У медсестры одобрен костюм, но конкретный файл не указан: два сохранённых кандидата показаны отдельно без заявления, что какой-то из них окончательно утверждён. Домашний тест ещё не оценён.

В карточках используются уменьшенные lossless-WebP-превью; при открытии доступны полные исходные PNG без изменения разрешения. Каждый оригинал проверяется при сборке по размеру и SHA-256. В исходниках старых прототипов и изображениях нет изменений. Оценки и комментарии сохраняются только в `localStorage` браузера: их нужно скопировать или скачать и отправить в чат; серверу они не передаются. Это не внедрение в игру.

Сборка расширяет существующий Vercel-проект Night Step, **сохраняя его на `/`**; каталог находится на `/collection/`, остальные прототипы — под `/collection/motion/`. Существующие Vercel-проекты Yoga и V3 не изменяются.

```sh
# Из корня репозитория; Node.js 22.17+.
npm --prefix ArtStudio/Prototypes/hero01-night-step ci
node ArtStudio/Prototypes/hero01-costume-gallery/scripts/catalog.test.mjs
node ArtStudio/Prototypes/hero01-costume-gallery/scripts/build.mjs
node ArtStudio/Prototypes/hero01-costume-gallery/scripts/serve.mjs 5189
# В другом терминале:
node ArtStudio/Prototypes/hero01-costume-gallery/scripts/browser-qa.mjs
```

Проверка браузера использует установленные в Night Step `playwright-core` и `@sparticuz/chromium`; `GALLERY_URL` задаёт публичный адрес, а `GALLERY_SCREENSHOT` — необязательный файл скриншота. Пять сцен и touch-кнопка тестируются в эмуляции Chromium с программным WebGL; это не проверка Safari, физического устройства или FPS.
