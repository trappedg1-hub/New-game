## Как попробовать

Касайтесь ближней стопы, ног, рук, лица или волос непосредственно на изображении. Кнопки под изображением дублируют основные реакции и удобны на небольших экранах. В настройках доступны интенсивность, пауза мягкого idle, ручное моргание, вид лица и сравнение с оригиналом. Сфокусировав изображение, можно запускать реакции клавишами 1–6.

Реакция начинает движение сразу: основной импульс достигает пика примерно за 0,14 с, остальные суставы догоняют примерно к 0,27 с, а возврат длится около двух секунд. Новое касание не ставится в длинную очередь; предыдущая реакция плавно уступает место новой. Дыхание и волосы остаются мягкими. Суставы плеча/локтя/кисти и бедра/колена/голеностопа независимые. Механизм использует технологию PixiJS FK/weighted skinning, как в V3, но точки суставов и хореография настроены специально под эту позу. Опорная стопа закреплена у пола и движется скромнее приподнятой.

```bash
cd ArtStudio/Prototypes/hero01-night-step
npm ci                         # Node.js 22.17 или новее
npm run dev                    # Vite, привязка к 0.0.0.0
```

Для сборки и проверок:

```bash
npm test                       # суставы, реакции, контроль исходника
npm run build                  # production-сборка
npm run qa:browser             # Chromium/Playwright, мышь и эмулированные касания
```

`qa:browser` запускает собственный локальный Vite-сервер, а Chromium извлекает из dev-зависимости. Переменная `CHROMIUM_PATH` позволяет указать другой совместимый браузер; `TMPDIR` — изолировать его временные файлы. Для восстановления производных изображений, если нужно, отдельно установить зависимости и выполнить:

```bash
python3 -m venv .venv
.venv/bin/pip install -r scripts/requirements.txt
.venv/bin/python scripts/build-assets.py
```

Генератор перед записью производных проверяет SHA утверждённого PNG. В нейтральной позиции программная RGB-композиция слоёв совпадает с исходником (максимальная разница 0 из 255); итоговый WebGL-растр при масштабировании может незначительно отличаться из-за фильтрации и смешивания. Плотность canvas следует реальному `devicePixelRatio` устройства, исходная текстура не уменьшается.

## Что проверено и ограничения

- Нажатия мышью и эмулированные касания в 13 зонах проверены в Chromium; протестированы отмена реакции при прокрутке и мультитаче, пауза, моргание, клавиатура, увеличение и сравнение. Отдельно проверена компоновка шириной 320–650 CSS-пикселей и режим `prefers-reduced-motion`.
- На выборке всех реакций, трёх вариантов и максимальной интенсивности в Chromium не обнаружено перевёрнутых треугольников сетки. Для основных конечностей сравнение полного и прореженного меша в выбранных кадрах не показало различий в пикселях. Дополнительно осмотрены кадры экстремальных поз, но это не гарантия отсутствия видимых швов во всех кадрах и на всех устройствах.
- Утверждённый исходник **1024 × 1024, не 4K**. Его разрешение не снижено и искусственный апскейл не применён.
- Исходник плоский: скрытых волос, фона и частей тела для движения в нём нет. Подложки восстановлены приблизительно, а закрытые глаза получены локальной обработкой. При сильном движении, особенно вокруг стопы, рук и перекрытий, возможны ореолы, тени или деформации; это нельзя полностью устранить без настоящих послойных исходников.
- Это проверки в headless Chromium с программным WebGL и эмуляцией сенсорного экрана. Физический телефон, Safari/WebKit и аппаратный GPU отдельно не проверялись; производительность и FPS на них не заявляются.
