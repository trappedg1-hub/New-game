# HERO-01 V2 · проверка — 2026-11-04

## Локальная проверка

- `npm test`: 8/8. Проверены непрерывность и интервалы морганий, дыхание, фиксированное лицо и нижняя часть тела, две разные фазы прядей с закреплёнными концами, ограничение интенсивности, ориентированные треугольники сетки, хэш исходника и размеры производных PNG.
- Основная сетка адаптивна: 3015 вершин вместо 16 425 в равномерном варианте с шагом 16 px. В областях обеих прядей общая и локальные сетки имеют совпадающие вершины и диагонали. В одном 3-секундном прогоне программного Chromium на мобильном размере медианный интервал кадра снизился примерно с 66,6 до 33,3 мс; это измерение среды теста, не прогноз FPS на iPhone.
- Chromium 133 headless с программным WebGL: `npm run test:ui` успешно для dev и собранной production-версии. Проверены две панели, управление, ручное моргание на паузе, zero intensity, mobile 390 × 844, уменьшенное движение, ошибки запросов/консоли.
- В нейтральном кадре фактически отрисованные WebGL-панели: среднее абсолютное отличие `0.0253 / 255` по RGBA, максимум `25 / 255`; рендер sprite и нескольких mesh не является побитно идентичным. Обе панели используют одну и ту же утверждённую исходную текстуру. Восстановление двух прядей до WebGL даёт среднюю ошибку `0.0066 / 255` или меньше по RGB в своих прямоугольниках, максимум меньше `0.58 / 255` до округления.
- При 150% за 93 отсчёта в 18,4 с максимальное смещение основной сетки составило `7.06 px` исходника, минимальное ориентированное произведение треугольника `212.21` (при исходном `256`); лицо и область ниже y=1950 неподвижны. Фактический WebGL-тест с включением/выключением независимого сгиба изменил `0.050%` пикселей в панели в одном выбранном кадре; при нулевой силе движения различие исчезло.
- На крупном плане 26 последовательных пар моргания с шагом 1/60 с: максимальное среднее изменение между кадрами `0.3891 / 255` по всей панели, изменение числа непрозрачных пикселей — 0. Эта метрика не исключает локальных швов. Вручную осмотрены промежуточные и закрытые глаза и движения обеих прядей при увеличении; выбран мягкий, ограниченный вариант.
- `npm run build` и `npm audit --audit-level=low` успешны; на момент проверки найдено 0 уязвимостей. Повторная подготовка V2 дала идентичные SHA-256 всех новых PNG и JSON. Утверждённый исходник сохранил SHA-256 `91111189c23d1d7ac424e85d3406202bf028e8d3330ae8c50b33223312f236fd`.

## Ограничения проверки

Программный Chromium — не физический мобильный браузер. Результаты относятся к отобранным кадрам и не доказывают отсутствие всех артефактов. Большая часть персонажа всё ещё одна плоская текстура; возможны локальные мягкие швы вблизи вырезанных прядей и век.

- До оптимизации сетки независимый прогон Playwright WebKit в GitHub Actions с параметрами iPhone 13 прошёл загрузку, размеры, движение, паузу, ручное моргание, reduced motion, хэш исходника и шесть текстур. Это Linux-эмуляция с программным WebGL, а не физический iPhone.
