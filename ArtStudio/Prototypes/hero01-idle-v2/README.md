# HERO-01 · Idle motion study V2

Отдельный экспериментальный прототип на PixiJS 7.4.3/Vite. Он основан на [`../hero01-idle/`](../hero01-idle/), но не меняет V1, утверждённые файлы или игровые сцены. Это не новый утверждённый арт и не полноценный послойный production-риг.

**Стабильная V1:** https://hero01-idle-prototype.vercel.app/

**V2 без входа (публичное production-зеркало отдельного проекта):** https://hero01-idle-v2-prototype.vercel.app/

**V2 Preview:** https://hero01-idle-v2-prototype-gx0w0d35r-trappedg1-hub.vercel.app/ — Vercel требует авторизацию. В обоих адресах одна и та же версия прототипа; подробности проверки — в [`QA.md`](QA.md).

## Что изменено

- Вдох и более продолжительный выдох с коротким отдыхом; движение верхней части тела и плеч ограничено. Часть ткани следует за дыханием с небольшим запаздыванием.
- Левая и правая области волос используют разные плавные фазы. **Две небольшие отдельные пряди** вырезаны из исходника, а их фон локально восстановлен: поверх общей сетки они сгибаются независимо и закреплены на концах. Это настоящие отдельные фрагменты, но не разложение всей причёски на слои.
- Локальное веко сначала прикрывает исходную радужку без её сжатия, затем переходит к выровненным экспериментальным состояниям почти закрытых/закрытых глаз. Для каждого глаза подготовлен атлас из 33 кадров с интерполяцией соседних кадров. Длина вдоха/выдоха и интервалы морганий различаются; иногда возникает двойное моргание.
- Адаптивная сетка сохраняет детальные совпадающие вершины вокруг прядей, но уменьшает нагрузку в статичных областях.
- Для сравнения доступны вид в полный рост и крупный план, пауза, ручное моргание и сила движения. При `prefers-reduced-motion` анимация начинается на паузе; ручное моргание и ручное включение остаются доступны.

## Ограничения

Утверждённый исходник остаётся плоским. Кроме двух локальных прядей, волосы, ткань, кожа и фон в соответствующей области по-прежнему деформируются **одной общей сеткой**; настоящей многослойной окклюзии и восстановленных скрытых частей нет. Ресницы/подложка экспериментальны: на сильном увеличении возможны небольшие мягкие швы или следы интерполяции, особенно у пересечения волос и при почти закрытых глазах. Для полноценной production-анимации нужны отдельные согласованные слои и ручная доводка. Проверка Playwright WebKit на Linux с размерами iPhone не заменяет проверку Safari на физическом устройстве.

## Запуск и проверки

Нужны Node.js 20+ и браузер с WebGL:

```bash
cd ArtStudio/Prototypes/hero01-idle-v2
npm ci
npm run dev
```

Сервер слушает `0.0.0.0` для Arena-превью; используйте его только в доверенной сети. Доступ к файловой системе Vite ограничен папкой прототипа и одним утверждённым исходником.

```bash
npm test                 # движения, границы меша, хэш, атласы и пряди
npm run build            # production-сборка
npm run preview          # локальная проверка сборки
```

Для автоматической browser-проверки при работающем dev-сервере: `CHROME_PATH=/path/to/chromium npm run test:ui`; при другом адресе укажите `HERO_TEST_URL`, для собранной версии — `HERO_PRODUCTION=1`. Тестовый Chromium использует программный WebGL. Конкретные результаты и пределы проверок приведены в [`QA.md`](QA.md).
