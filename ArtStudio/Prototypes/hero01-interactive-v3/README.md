# HERO-01 · интерактивный прототип V3

Изолированное продолжение **утверждённого V1** из [`../hero01-idle/`](../hero01-idle/). V2 не использовался как основа. Исходный арт и V1/V2 не изменяются. Это эксперимент, не утверждённый финальный риг.

## Запуск

```sh
cd ArtStudio/Prototypes/hero01-interactive-v3
npm ci
npm run dev
# отдельная production-сборка
npm test && npm run build && npm run preview
```

`src/rig.js` импортирует утверждённый исходник из `ArtStudio/Generated/Approved/`, поэтому для локальной сборки необходим весь репозиторий. PixiJS остаётся **7.4.3**, как в V1; Vite и версии зависимостей также сохранены. Два Pixi-приложения и 51 × 149 `SimplePlane` унаследованы от V1.

## Использование

Режим «Персонаж» увеличивает область касания; «Сравнение» возвращает оригинальную двухпанельную схему V1. Доступны полный рост/лицо, пауза, ручное моргание и сила движения. На тач-экране и мышью коснитесь разных областей; браузерная прокрутка свайпом сохраняется. На сфокусированной области персонажа клавиши 1–9 доступны как альтернативный ввод. При `prefers-reduced-motion` V1 idle запускается на паузе, но отдельное прикосновение и ручное моргание всё ещё работают.

Попадания: макушка, волосы, лицо, каждое плечо, каждая рука и кисть, верхняя часть тела, талия и каждая нога. Полигоны заданы в исходных координатах 1184 × 3488, следуют деформированной сетке и трансформации камеры. При перекрытии кисть имеет приоритет над лицом, лицо — над волосами. Фон не активен. Удержание или свайп не считаются нажатием; один завершённый tap обрабатывается единожды. Для технической проверки откройте `?debug=1`: появятся контуры областей. По умолчанию их нет. `?qa=1` включает только диагностический объект для тестов, не контуры.

## Архитектура и ограничения

- Исходное дыхание, волосы, ткань, моргание и трансформации V1 продолжают работать. При отсутствии реакции выполняются те же уравнения; новые смещения добавляются поверх V1 и жёстко ограничены.
- Реакции используют `IDLE`, `TOUCH_REACTION`, `SPECIAL_REACTION`, `RETURN_TO_IDLE`, вариации по зоне, короткий cooldown и ограниченную историю/комбо. Новое прикосновение заменяет цель без накопления очереди; независимые часы реакции продолжают работать и на паузе V1.
- Выражения: нейтральное, радостное, удивлённое, застенчивое, с румянцем, игривое, сонное и грустное. Это V3-only маски рта и сонных век плюс полупрозрачный румянец; обычные глаза и моргание V1 остаются на месте. Переходы быстрые и мягкие, при сильном увеличении может быть заметна краткая мягкость/двоение линий. Подробности происхождения — в [`artifacts/PROVENANCE.md`](artifacts/PROVENANCE.md).
- Оригинальное изображение **плоское**: волосы, одежда и тело не разделены на самостоятельные слои или кости. Движение — небольшая деформация участков общей сетки; кисти, лицо и ноги отвечают выражением, а не отдельной скелетной анимацией. Брови не отделены и не анимируются. Нет смены лица, костюма или пропорций исходника.

## Проверки и восстановление

- `npm test`: тесты V1 и V3 (геометрия, попадания, состояния, cooldown, источники, выражения).
- `npm run test:ui`: реальная Pixi/WebGL-сцена в Playwright; `HERO_BROWSER=webkit` и `HERO_DEVICE=mobile|landscape` выбирают другие профили. `HERO_TEST_URL` задаёт URL; `HERO_V1_TEST_URL` дополнительно включает сравнение кадров с запущенным V1 dev-сервером `?qa=1`.
- `PYTHONPATH=... python scripts/prepare_expressions.py` пересоздаёт только V3-слои из локальных экспериментальных кандидатов с зависимостями `scripts/requirements.txt`.
- Фактические результаты и ограничения проверки — [`QA.md`](QA.md); состояние/восстановление — [`PROGRESS.md`](PROGRESS.md).
