# HERO-01 · интерактивный прототип V3

Изолированное продолжение утверждённого V1 из [`../hero01-idle/`](../hero01-idle/). V2 не использовался как основа; V1/V2 и утверждённый исходный арт не изменяются. Это эксперимент, не утверждённый финальный риг.

Публичная версия отдельного проекта: **https://hero01-interactive-v3-prototype.vercel.app/**. Это production-ссылка экспериментального V3, а не Vercel Preview. Фактическая версия и результаты проверок указаны в [`PROGRESS.md`](PROGRESS.md) и [`QA.md`](QA.md).

## Запуск

```sh
cd ArtStudio/Prototypes/hero01-interactive-v3
npm ci
npm run dev
npm test && npm run build && npm run preview
```

Для сборки нужен весь репозиторий: V3 использует исходник из `ArtStudio/Generated/Approved/`. Версия и технология совпадают с V1: **PixiJS 7.4.3**, два Pixi-приложения и один `51 × 149` `PIXI.SimplePlane` на плоском изображении 1184 × 3488. Vite и lockfile не менялись.

## Использование

Режим «Персонаж» увеличивает область касания; «Сравнение» возвращает двухпанельную схему V1. Доступны полный рост/лицо, пауза, ручное моргание и сила движения. Области реагируют на мышь и прикосновения; клавиши 1–9 работают на сфокусированной области как альтернативный ввод. При `prefers-reduced-motion` V1 idle запускается на паузе; отдельное прикосновение и ручное моргание по-прежнему работают.

Существующие полигоны следуют деформированной сетке; при перекрытии кисть приоритетнее лица, а лицо — волос. Фон не активен. Удержание, перемещение и несколько одновременных пальцев не считаются tap. На Pixi-холсте задан `touch-action: pan-y`: обычный вертикальный свайп остаётся доступен для прокрутки страницы, но pinch/double-tap zoom, начатые на холсте, не запрашиваются. Страница вне холста остаётся масштабируемой. Отладочные контуры — `?debug=1`; диагностический объект для тестов — `?qa=1`.

## Реакции

Названия сторон соответствуют существующей разметке исходной картинки. К движениям добавляются прежние выражения, а дыхание и движение груди V1 продолжаются параллельно. Каждая зона циклически использует три ограниченных варианта направления, силы и времени.

| Зона | Физический отклик поверх V1 | Сохранённые выражения |
| --- | --- | --- |
| Макушка | наклон и сдвиг головы, очень небольшое увеличение/уменьшение как приближение/отступление; волосы следуют позже | радость, сонливость, игривость |
| Волосы | небольшое движение головы, два широких участка волос с запаздыванием и плечи | сонливость, радость, застенчивость |
| Лицо | наклон/сдвиг головы и обратное изменение масштаба | удивление, застенчивость, игривость |
| Левое / правое плечо | асимметричный подъём плеча, поворот торса, рука и волосы | радость/игривость; радость/застенчивость |
| Левая / правая рука | локальный сдвиг руки, плеча, торса и волос | игривость/удивление; радость/удивление |
| Левая / правая кисть | общая реакция поднятой кисти и головы / локальная реакция опущенной кисти и предплечья | застенчивость/радость/игривость; радость/застенчивость/игривость |
| Верх торса | сдвиг корпуса и плеч, дыхание остаётся активным | румянец, застенчивость |
| Талия | сдвиг позы, торса и ткани | удивление, игривость |
| Левая / правая нога | небольшое перераспределение веса через область ног и талии, обувь зафиксирована | удивление/грусть; грусть/удивление |

Быстрые повторения и комбинации сохраняют особые выражения (`blushing`, `playful`). Контроллеры координируют `IDLE`, `TOUCH_REACTION`, `REACTION_TRANSITION`, `RETURN_TO_IDLE` и `SPECIAL_REACTION`, короткий cooldown, ограниченную историю и плавное прерывание без очереди старых целей. Часы реакции работают независимо от паузы V1.

## Архитектура и честные ограничения

- Уравнения V1 для дыхания/груди, волос, ткани и моргания перенесены **без изменения** в `src/animation/idle-controller.js`. `src/animation/` разделяет профиль и управляющие вклады головы, волос, плеч, рук, торса, ног и одежды; `src/reactions.js` и `src/pixi-expressions.js` отвечают за состояние и выражение. Суммарная реакция вычисляется один раз на кадр, ограничивается и добавляется к существующей сетке. Hitbox-полигоны следуют ей.
- Глаза, моргание и экспериментальные выражения двигаются общим контейнером вместе с жёсткой областью лица. Семь состояний выражения плюс нейтральное остаются из V3; они не помещены в Approved. При сильном увеличении прежние переходы рта могут давать краткую мягкость/двоение, а V1-моргание — уплощение глаз.
- Это **2D-деформация**, а не скелет или поворот головы в 3D. Небольшое изменение масштаба — только визуальный намёк на движение к камере/от неё. Волосы и одежда не отдельные физические слои; задержка применяется к широким областям сетки, а не к индивидуальным прядям. Скрещённые ноги не имеют самостоятельных суставов, шага и скрытых поверхностей.
- Поднятый палец нарисован поверх лица в исходнике, поэтому он не отделён от головы; движения этой зоны координируют голову и верх руки, но не являются независимым движением пальцев/сустава. Опущенная кисть имеет локальную деформацию, а не отдельную кость.
- В `artifacts/experiments/handless_face_underlay_study.png` сохранён AI-кандидат подложки без руки. Он не утверждён, не загружается и не заменяет исходник: совпадение и маскировка границ не доказаны. Подробности — [`artifacts/PROVENANCE.md`](artifacts/PROVENANCE.md). Для убедительных независимых пальцев, суставов, прядей и настоящих поворотов нужны согласованные раздельные слои/дорисовка скрытых частей и отдельная художественная проверка.

## Проверки

- `npm test` — тесты V1 и V3: зоны, выражения, варианты и состояние, следование головы/лица, возврат и прерывания, 1365 стресс-поз сетки, сохранность исходника.
- `npm run test:ui` — настоящая Pixi/WebGL-сцена в Playwright. `HERO_BROWSER=webkit`, `HERO_DEVICE=mobile|landscape`, `HERO_TEST_URL` и необязательный `HERO_V1_TEST_URL` выбирают движок/размер/адрес и сравнение с запущенным V1.
- `PYTHONPATH=... python scripts/asset-test.py` проверяет прежние производные выражений и неизменность исходника. Новая ручная подложка не является runtime-ассетом.
- Фактически проведённые проверки, показания геометрии и их пределы — [`QA.md`](QA.md). Playwright WebKit с размером iPhone не равен тестированию на физическом iPhone Safari.
