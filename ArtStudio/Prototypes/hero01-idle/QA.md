## Локальные проверки

Проверено в Chromium 133 headless с программным WebGL, на desktop 1440 × 1100 и mobile 390 × 844; дополнительно запущена собранная production-версия. Это не гарантия одинакового результата на всех браузерах, GPU и разрешениях.

- `npm test`: 5/5 тестов проходят. Проверяются ограниченная непрерывная огибающая моргания, нулевое движение лица/нижней части тела, нулевая интенсивность, отсутствие переворотов треугольников, непрерывность смещения между соседними 60 fps samples, хэш утверждённого исходника и размеры шести слоёв.
- `npm run test:ui`: пройдены Pixi/WebGL-загрузка, две панели, переключение масштаба, пауза, моргание на паузе, ползунок, mobile и `prefers-reduced-motion`; ошибок консоли и запросов при прогоне нет. То же базовое поведение проверено на production-сборке.
- При нулевом движении сравнение фактически отрисованных WebGL-панелей на desktop: среднее абсолютное отличие `0.0276 / 255` по RGBA, максимум `8 / 255` (разная растеризация sprite/mesh). Обе используют одну и ту же исходную текстуру; это не утверждение о побитовом равенстве растеризации.
- На 150% и 93 временных отсчётах за 18,4 с максимальное смещение вершины `22.67 px` исходника, минимальное ориентированное произведение для обоих треугольников ячейки `386.86` (положительное, переворотов на этих отсчётах нет). Лицо и область ниже y=1950 остаются неподвижны сеткой.
- В увеличенном режиме проверены 26 последовательных пар моргания с шагом 1/60 с: максимальное среднее изменение между кадрами `0.4243 / 255` по всей RGBA-панели, изменение числа непрозрачных пикселей — 0. Пустые/мигающие целиком кадры при этом тесте не обнаружены. Это численная проверка, а не доказательство отсутствия локальных артефактов.
- Визуально проверены открытое, промежуточные и закрытое состояния. Первые варианты с одной inpaint-подложкой давали заметные двойные линии и были отброшены; текущая версия использует закрытое веко из выровненного экспериментального кандидата. При крупном увеличении возможна лёгкая деформация/шов в переходе; это известное ограничение плоского исходника, не финальный production-риг.
- `npm run build` и `npm audit --audit-level=low` проходят, обнаружено 0 уязвимостей на момент проверки. Хэш утверждённого исходника совпадает с записанным в `public/derived/rig.json`.
