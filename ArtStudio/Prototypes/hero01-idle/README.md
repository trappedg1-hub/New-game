# HERO-01 · Idle motion study

Изолированный рабочий прототип анимации одного персонажа на PixiJS 7.4.3. **V1 — основная, утверждённая пользователем база анимации HERO-01.** Это прототип, не игра и не утверждение нового изображения.

## Решение по версиям

Сохранять V1 и её анимацию неизменными; [V2](../hero01-idle-v2/README.md) остаётся отдельным экспериментом и не заменяет V1. Утверждённый исходный арт не изменять. Любую будущую разработку, включая V3 с touch-взаимодействиями, следует вести **от V1**, отдельно от сохранённой базы. V3 пока не начинать: ожидать дальнейших инструкций пользователя.

## Публичная версия

[Vercel · HERO-01 Idle](https://hero01-idle-prototype.vercel.app/) — опубликованная сборка существующего прототипа. Проверки и их ограничения описаны в [`QA.md`](QA.md).

Проект Vercel подключён к этому репозиторию. Production-сборка создана из коммита `f3ef0305b55f1b802051915732845ade2ac73cc7`; ветка production в настройках Vercel — `main`. Поэтому новые коммиты рабочей ветки `arena/680e6caa-new-game` создают preview и **не обновляют публичную production-ссылку автоматически**. В `main` прототип появится только после слияния; не меняйте production-ветку без учёта этого.

## Запуск

Нужны Node.js 20+ и браузер с WebGL:

```bash
cd ArtStudio/Prototypes/hero01-idle
npm ci
npm run dev
```

Откройте адрес, который покажет Vite. Сервер слушает `0.0.0.0` для Arena-превью; используйте его только в доверенной сети. Доступ по файловой системе ограничен папкой прототипа и одним утверждённым исходником. Для production-сборки: `npm run build`, затем `npm run preview`.

Слева показан неподвижный оригинал, справа — тот же исходник в движении. Доступны вид в полный рост и крупный план лица, пауза/продолжение, ручная проверка моргания и ползунок силы **сетки** (частоту морганий он не меняет). Ручное моргание работает и на паузе. При `prefers-reduced-motion` сцена начинает на паузе; её можно включить вручную.

## Исходник и экспериментальные слои

- Исходное изображение: [`Generated/Approved/HERO-01_outfit02_playful_maid.png`](../../Generated/Approved/HERO-01_outfit02_playful_maid.png), 1184 × 3488, SHA-256 `91111189c23d1d7ac424e85d3406202bf028e8d3330ae8c50b33223312f236fd`. Рантайм читает его напрямую; оно **не перезаписывается**.
- Исходник плоский. Тело, волосы и одежда в текущем риге — одна текстура на общей деформируемой сетке, а не настоящие отдельно нарисованные слои. Дыхание, боковое движение волос и движение края юбки задаются небольшими, плавными локальными весами. Лицо и нижняя часть тела не деформируются сеткой.
- Для каждого глаза подготовлены три маленьких RGBA-фрагмента: открытый глаз из исходника, экспериментальная подложка и закрытое веко. Исходные глазные фрагменты плавно сжимаются по наклону, в конце соединяются с закрытым веком. Это локальная анимация глаз, а не переключение целых несвязанных изображений.
- Закрытые веки взяты из **экспериментального AI-кандидата** `artifacts/closed_eyes_candidate.png`, выровненного по кропу исходника; текстура под ними восстановлена inpaint. Полное сгенерированное лицо и любые его изменения вне небольших масок глаз в сцене не используются. Ни кандидат, ни фрагменты не считаются утверждённым артом. Происхождение и исходный запрос описаны в [`artifacts/PROVENANCE.md`](artifacts/PROVENANCE.md).
- Слои, матрица выравнивания и привязки находятся в `public/derived/`. Повторная подготовка возможна через `scripts/prepare_blink.py` и `scripts/requirements.txt`. Результаты сохраняются только внутри прототипа.

## Что пока не решено

Это ограниченный 2D-меш, а не полноценный послойный риг или физическая симуляция. Волосы, фон, тело и ткань в соответствующих областях деформируются вместе: нет истинного параллакса, независимой перекрываемости и восстановленных скрытых деталей. При сильном увеличении промежуточное веко/радужка могут выглядеть слегка уплощёнными, возможны мягкие швы подложки; закрытые ресницы — экспериментальная интерпретация. Реальные слои (передние/задние волосы, веки, глаза, тело, руки, части одежды и восстановленные скрытые области) и ручная доводка нужны для более качественного production-рига. Это потребует отдельного согласования нового арта.

## Проверки

```bash
npm test                 # математика моргания, сетка и границы движения
npm run build            # production-сборка
```

Для браузерной проверки запустите `npm run dev` в другом терминале, затем укажите путь к установленному Chromium:

```bash
CHROME_PATH=/path/to/chromium npm run test:ui
```

Также можно указать `HERO_TEST_URL`, а для уже собранного `npm run preview` — `HERO_PRODUCTION=1`. Скрипт тестирует WebGL, исходник рядом с ригом, элементы управления, мобильный размер и режим уменьшенного движения; его тестовый Chromium запускается без sandbox и с программным WebGL. Подробности конкретного прогона и его пределы — в [`QA.md`](QA.md).
